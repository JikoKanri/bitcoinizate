# Registro de revisión de arc cards

Este registro sigue el orden de `CHANCE_CARDS` en `game.js`. En cada ejecución se revisa una sola card y se agrega su ID a la lista de completadas. La siguiente card pendiente es la primera del arreglo cuyo ID no aparece aquí.
